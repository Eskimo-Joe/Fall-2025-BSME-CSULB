The cubic spline method of numerical interpolation is poor for scenarios like this where the increment is very small. This method resulted in the highest error of all because it over assumes how erratic the base function is, as it fluctuates at high peaks and valleys between the given data points. The Lagrange polynomials performed differently on the different values. For $x=0.3$, the 3rd degree polynomial performed poorly, likely because the true function is close to linear and a 3rd degree polynomial assumes the function is accelerating. The first and second degree polynomial performed the same by coincidence, likely because the function does not seem to be accelerating or decelerating rapidly. At $x=0.9$, the function is accelerating rapidly because it is converging towards zero. This allowed the 3rd degree polynomial to make an accurate prediction. Even still, the 3rd degree weas only slightly better than the 1st degree polynomial, and the 2nd degree polynomial performed best for both values.
