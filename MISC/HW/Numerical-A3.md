## 4
Polynomial: $\sum e^2=50.52786296$
Power Series: $\sum e^2=51.99520283$
The value e represents the error from the predicted flow from the measured flow. The $\sum e^2$ value normalizes positive and negative errors to get an understanding of the total amount of error across the dataset. If one equation had to be chosen, the polynomial is a more accurate method of characterization because the $\sum e^2$ value is slightly lower. However if necessary, either one can be used to make relative predictions of flow given a certain pressure with less than 5% error even at low pressures.
